An AI career platform that takes computing professionals from resume upload to submitted application through a Tinder-style swipe interface. A four-agent LangGraph system ranks live listings with FAISS semantic matching in under 250ms, surfaces skill gaps with learning recommendations and verifies competencies through quizzes. A single right swipe fires the Optimization Agent, tailoring the resume against the live job description via RAG and generating a cover letter before the Application Agent submits automatically.
